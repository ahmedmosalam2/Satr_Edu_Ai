# 🏛️ دليل معماري مشروع Satr Edu AI

هذا الملف يشرح كيف تترابط مكونات النظام لخدمة الـ "الوكيل الذكي" (Agent).

## 1. محرك البيانات (The Data Engine)
- **`src/parsers/`**: مسؤول عن قراءة الملفات. إذا كان الملف "صورة"، يتم استدعاء **Surya OCR** عبر الـ `OCRController`.
- **`src/pipeline/`**: يأخذ النص المستخرج ويقوم بعملية الـ `Chunking` (التقسيم) والـ `Embedding` (التشفير الرقمي).
- **`src/controllers/NLPController.py`**: هو "مدير العمليات" الذي يربط الـ RAG (استرجاع المعلومات) بالـ LLM.

## 2. الوكيل الذكي (The AI Agent)
- الـ Agent موجود في `src/routes/nlp.py` و `src/controllers/NLPController.py`.
- **وظائف الوكيل:**
    1. **Socratic Tutor**: لا يعطيك الإجابة مباشرة، بل يساعدك على التفكير.
    2. **Tool Use**: يستطيع استدعاء وظيفة "توليد الامتحانات" أو "البحث في المستندات" تلقائياً.
    3. **Multi-RAG**: يستخدم البحث بالمتجهات (Vector Search) والبحث بالكلمات المفتاحية (Keyword Search) معاً لضمان أدق إجابة.

## 3. دور الـ OCR (Surya) في الليلة دي
بدون Surya، لو رفعت صورة أو كتاب ممسوح سكانر، الـ Agent هيكون "أعمى" مش شايف حاجة. Surya هي "العين" اللي بتخلي الـ Agent يقدر يقرأ الكتب الممسوحة ضوئياً ويجاوب منها.

## 4. المجلدات التقنية
- **`src/models/`**: تعريف الجداول (Collections) في MongoDB.
- **`src/helpers/`**: الاتصال بالخدمات الخارجية (Gemini API, Qdrant Client, Surya Service).
- **`main.py`**: نقطة الانطلاق اللي بتجمع كل الـ Routes دي وتشغل السيرفر.
